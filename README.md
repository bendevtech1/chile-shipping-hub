# 📦 Chile Shipping Hub (Cotizador Logístico Multicanal)

Plataforma full-stack diseñada para automatizar y comparar en tiempo real las tarifas y tiempos de entrega de los principales couriers de Chile (Starken, Chilexpress y Blue Express).

---

##  Características Principales
* **Consultas Concurrentes (Backend):** Utiliza `Promise.all` en Node.js para consultar múltiples servicios de forma paralela, optimizando el rendimiento y reduciendo la latencia.
* **Clean Architecture:** Separación clara de responsabilidades con un módulo de servicios (`shipping.service.js`) desacoplado de las rutas principales.
* **Interfaz de Usuario Moderna:** Desarrollada con React y animaciones fluidas usando **Framer Motion**, adaptada a un diseño *Dark Mode* minimalista.

---

##  Tecnologías Utilizadas
* **Frontend:** React, Vite, Framer Motion.
* **Backend:** Node.js, Express, CORS.
* **Entorno:** REST APIs, Arquitectura Asíncrona.
